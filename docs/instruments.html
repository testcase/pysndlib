CLM Instruments#

pysndlib ships the classic CLM instrument collection. An instrument is simply a function that is called inside a pysndlib.clm.Sound context and writes samples (see Sound Context Manager):

import pysndlib.clm as clm
from pysndlib.instruments import fm_violin

with clm.Sound('violin.wav', channels=1, srate=44100):
    fm_violin(0.0, 2.0, 440.0, 0.4)

Instruments can be freely mixed in one Sound; each writes into the current output at its own start time.

Where to find them#

The instruments live in two modules:

  • pysndlib.instruments – the classic collection (~48 instruments, ported from clm-ins.scm, generators.scm, and related files in the sndlib distribution). The instrument files are compiled with cython when pysndlib is built, so they run at native speed.

  • pysndlib.clm_ins – additional translations (vox, drone, canter).

Note

Import instruments directly, e.g.:

from pysndlib.instruments import fm_violin

Do not use import pysndlib.instruments.fm_violin – the package __init__ re-exports each instrument function, which shadows the submodule of the same name; the plain import binds the function rather than the module.

Reverb instruments#

The reverb instruments (jc_reverb, nrev, jl_reverb) are not called directly: they are handed to Sound via the reverb argument, and pysndlib runs them over an intermediate reverb file:

from pysndlib.instruments import jc_reverb, fm_bell

with clm.Sound('bells.wav', channels=1, srate=44100,
               reverb=jc_reverb, reverb_data={'decay_time': 2.0},
               reverb_channels=1, revfile='bells.rev'):
    fm_bell(0.0, 2.0, 440.0, 0.4)

Writing your own instrument#

An instrument is just a function that computes its own sample loop and writes with clm.outa and friends:

def sine_bell(beg, dur, freq, amp):
    start = clm.seconds2samples(beg)
    length = clm.seconds2samples(dur)
    osc = clm.make_oscil(freq)
    ampe = clm.make_env([0, 0, 5, 1, 100, 0], scaler=amp, duration=dur)
    for i in range(start, start + length):
        clm.outa(i, clm.env(ampe) * clm.oscil(osc))

The notebooks include a full introduction – writing an instrument, using the shipped collection, and speeding up your own instruments with cython (notebooks 04 and 05 in the repository’s notebooks/ directory).
